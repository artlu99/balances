## Commands

- `bun dev` — local dev server (Wrangler)
- `bun run deploy` — deploy with minification
- `bun types` — regenerate `worker-configuration.d.ts` after changing `wrangler.jsonc` bindings
- `bun test` — run tests

## Key facts

- **Package manager:** Bun (lockfile is `bun.lock`)
- **Tests:** `bun test` (uses `bun:test`)
- **Entry point:** `src/index.ts` (exports a Hono app)
- **Static assets:** `public/` (served via Workers Assets binding)
- **Env vars:** `VENICE_AI` API key, `RPC_URL`, `WALLET_ADDRESS`, `TOPUP_ADDRESS` — set in `.dev.vars` locally (see `.dev.vars.example`)
- **Generated file:** `worker-configuration.d.ts` is auto-generated by `wrangler types` and gitignored; the global `Env` interface it defines provides typed access to bindings
- **TypeScript:** strict mode, ESNext target, `nodejs_compat` compatibility flag
- **Dependencies:** Hono, itty-fetcher, viem (on-chain token reads via Base RPC)
